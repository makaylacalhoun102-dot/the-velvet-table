# THE VELVET TABLE

A fictional luxury fine-dining restaurant website, designed as an original digital media and web design portfolio project.

## Features
- Responsive, editorial-style homepage
- Interactive category-based dining menu
- Reservation preview form (demonstration only; no bookings or data submission)
- Restaurant story and experience sections
- Accessible navigation and form labels

## How to use
Open `index.html` in a browser, or publish the files using GitHub Pages. All three files (`index.html`, `styles.css`, `script.js`) must be in the repository root.

## Important
This is a fictional restaurant and design concept. Prices, menu items, and reservations are not real. Background photography loads from Unsplash and requires an internet connection. Photographs are third-party assets, not original work.
